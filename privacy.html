Privacy policy

Last updated: 2 November 2026

shorts-uploader is a personal automation used only by its owner. It runs on the owner's own computer.

What data it uses

With the owner's permission, it reads video files from a folder in the owner's Google Drive, uploads them to the owner's YouTube channel, and moves the uploaded files to another folder in the same Drive.

What it does not do

It does not collect data from other people. It does not sell, share or send Google user data to any third party. Access tokens are stored only on the owner's computer.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
